Generated by `tools/moniker-doc.py` from `src/moniker/*.moniker`. Edit the `.moniker`
files, not this page. The engine is Lumen's Moniker Core (`vendor/moniker/`); the
adapter that works out the families below is `src/moniker/skycaptain.js`.

trimming, and survivors are put back in `slot_order`. When a name is already taken,
trimmed words are promoted back in before a number is added.
